X01·X02는 G02·G03에서 필요성을 평가하고, 필요한 구현은 해당 단계에 포함한다. X03은 G01·G08에서 비교 필요성을 평가한다. X04는 터미널 방향을 유지하는 동안 확대하지 않는다는 기존 조건을 유지한다. 후보의 적용/보류 이유도 기록하며 후보 존재만으로 불필요한 기능을 전부 추가하지 않는다.

한 항목에서 외부 의존 검증만 남으면 미완료 상태를 유지하고 다음 독립 작업으로 이동한다. 물리 IME 등 사용자 관찰이 없는데 통과로 표시하지 않는다. 실제 연결 검증을 가짜 검사의 통과 뒤로 미루지 않으며, 회귀 검사는 변경에 맞게 병행한다. 모든 G 항목의 완료 기준을 감사하기 전 전체 goal을 완료하지 않는다.
