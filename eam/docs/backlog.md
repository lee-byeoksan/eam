# 목표 선택용 전체 작업 목록

2026-09-09. 사용자가 이 문서의 작업 순서를 정하고 순차 구현·검증하는 goal을 지정했다. [실행 계획](execution-plan.md)에서 순서와 상태를 추적한다. 완료된 검사를 반복하는 대신 각 항목의 남은 불확실성과 실제 사용상의 문제를 해결한다. 확장 후보의 적용 조건은 유지한다.

기반 완료: 독립 -Q 실행, 공식 구독 CLI 연결, Ghostel 기본 입력, 선택적 초안·외부 편집기 왕복, 작은 파일 수정·테스트·재개, 제한 기록 페이지, 출력 undo 비활성, 프로젝트 이름·프로세스 상태 표시. 1시간 스트림·200회 생성/종료·실패 정리 검사가 있다. 이는 모든 CLI 기능·GUI 사용성·장시간 안정성의 완전한 검증은 아니다.

## 현재 방향에서 남은 작업

| ID | 작업 | 남은 범위와 완료 기준 |
| --- | --- | --- |
| G01 | 실제 GUI 입력과 화면 사용성 | Claude·Codex 직접 입력, 한글 조합/삭제/영문 전환, 외부 편집기 왕복, 복사·붙여넣기, 스크롤·리사이즈·모드 전환·긴 경로 표시 확인. Computer Use와 물리 IME 결과 분리. 사용자에게는 물리 키보드 관찰만 요청. 발견한 재현 결함 수정 |
| G02 | 여러 프로젝트와 세션 접근 | 변경 후 실제 Codex 두 프로젝트 확인. 같은 제공자·같은 프로젝트의 복수 세션과 초안/종료 버퍼를 구분하고 원하는 대상으로 돌아가기. 실제 혼동이 남는 부분만 이름·표시·접근 방식 보완 |
| G03 | 대화 재개와 재시작 복구 | 알고 있는 ID뿐 아니라 목록에서 원하는 대화 선택→후속 작업까지 확인. 기존 목록 왕복 결과 재사용. 최신 빈 목록 관찰 원인 조사, ID 재개 대안 안내, 동일 대화 중복 writer 회피. 앱 기록 조회와 CLI 대화 재개를 구분한 사용 절차 완성 |

| G06 | 기록 조회 실용성 | 원시 ANSI를 그대로 보는 현재 경로에서 실제 과거 내용을 찾고 복사하기 어려운 점 확인. 필요한 검색·읽기 표시 개선만 구현. 원본 보존, 파일 읽기·표시 상한, AI 무호출을 유지하고 ANSI 화면 재구성 범위 결정 |
| G07 | 기록 저장 실패와 디스크 관리 | 현재 일반 쓰기 실패 격리 검증에 더해 권한·용량 부족·중도 종료 때 보존되는 범위를 확인. 원시 PTY 출력과 CLI 자체 대화 기록의 차이 안내. 크기 확인·내보내기·사용자 지정 정리 절차 마련. 전체 기록 보관 요구와 충돌하는 자동 삭제는 도입하지 않음 |

| G09 | 인증·네트워크 오류 복구 | 실제 계정 설정을 임의 변경하지 않고 가능한 범위에서 연결 실패·인증 만료·제한 도달 시 CLI 안내와 재시도/재개 경로 확인. 실제 발생·안전한 재현·미검증 구분. 앱의 자동 재요청·추가 호출 방지 원칙 유지 |

## 별도 선택할 확장 후보

사용자 테스트와 패키지화 후속 요청은 G10에 포함한다. 로컬 설치용 Emacs 패키지와 별도 `-Q` 실행을 준비하며, 코드·기록 경로 분리, Ghostel 네이티브 의존성 처리, 설치/업데이트/제거 시 기록 보존, 새 위치 설치 검증이 완료 기준이다. 패키지 준비를 기존 GUI·IME 검증 완료로 대신하지 않는다.

| ID | 후보 | 적용 판단 |
| --- | --- | --- |
| X01 | 전용 세션 목록 화면 | C-x b와 프로젝트 이름만으로 불편할 때 프로젝트·제공자·상태·초안·기록 접근을 모음. G02와 G03의 관찰을 근거로 범위 결정 |
| X02 | 최근 프로젝트·대화 바로가기 | 네이티브 재개를 유지하며 메타데이터 저장으로 접근 단축. 대화 중복 실행과 오래된 ID 처리 필요 |
| X03 | vterm 대조 실험 | Ghostel에 재현 가능한 입력·성능 문제가 남거나 사용자가 비교를 원할 때 같은 조건으로 측정 |
| X04 | 일반 버퍼/JSON UI 확대 | 현재 터미널 중심 방향을 변경하려는 경우에만 선택. CLI 기능과 승인 흐름 재구현 비용이 있으므로 현 경로의 필수 작업이 아님 |

현재는 이 목록의 필요 순서를 정의하고 순차 구현·검증하는 goal이 활성화돼 있다. 후보 X 항목은 적용 조건을 평가하며, 존재한다는 이유만으로 모두 구현하지 않는다. [현재 증거 대조](completion-audit.md).
